- Layout responsivo para desktop e celular

## Executando o projeto

Você precisa do [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/Muski360/portfolio-muski360.git
cd portfolio-muski360
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal, normalmente `http://localhost:5173`.

## Comandos

| Comando | Função |
| --- | --- |
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera a versão de produção em `dist/` |
| `npm run preview` | Visualiza o build localmente |
| `npm run lint` | Verifica o código com ESLint |

## Estrutura

```text

├── src/

│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── index.html
└── package.json
```

## Personalização

1. Edite os textos e o e-mail de contato em `src/App.jsx`.
2. Ajuste cores, tipografia e espaçamentos em `src/App.css`.
3. Confirme o domínio em `public/robots.txt`, `public/sitemap.xml` e `public/llms.txt`.
4. Atualize título e descrição em `index.html`.

## Deploy

Execute `npm run build` e publique o conteúdo gerado em `dist/`. O projeto pode ser hospedado na Vercel, Netlify, Cloudflare Pages ou GitHub Pages.
