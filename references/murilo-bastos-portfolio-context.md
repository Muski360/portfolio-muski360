# 9. Projeto principal

## Mentup

**Repositório:** https://github.com/Muski360/Mentup

### Resumo

Mentup é uma aplicação web criada para organizar **campeonatos de vôlei de praia**.

O projeto permite administrar boa parte do ciclo de um campeonato por meio de um sistema próprio, incluindo cadastro de usuários, campeonatos, equipes, jogadores, partidas, resultados e classificação.

É atualmente o projeto mais adequado para ocupar a posição de **featured project / projeto principal** do portfólio.

### Problema

Organizar um campeonato manualmente envolve vários elementos:

- participantes;
- equipes;
- modalidades;
- confrontos;
- fases;
- grupos;
- resultados;
- classificação;
- mata-mata.

O Mentup transforma esse processo em uma aplicação centralizada.

### Funcionalidades documentadas

- cadastro de usuários;
- login e logout;
- dashboard;
- criação de campeonatos;
- listagem de campeonatos por status;
- cadastro de times;
- cadastro de jogadores;
- configuração de formato do campeonato;
- geração automática de fases;
- geração de grupos;
- geração automática de partidas;
- suporte a fase de grupos;
- suporte a mata-mata;
- suporte a pontos corridos;
- registro de resultados por sets;
- atualização do vencedor das partidas;
- avanço automático do mata-mata;
- acompanhamento do campeonato;
- edição de campeonato, times e jogadores;
- encerramento de campeonato;
- exclusão de conta.

### Stack atual do Mentup

- PHP 8.3
- PostgreSQL
- PDO
- HTML
- CSS
- JavaScript
- Composer
- `vlucas/phpdotenv`
- Docker
- Apache
- Lucide Icons
- Supabase como opção de infraestrutura de PostgreSQL

### Arquitetura

O projeto apresenta separação em estruturas como:

- Controllers
- Models
- Services
- Views
- Config
- Assets

O banco de dados é relacional e contém entidades como:

- users
- championships
- teams
- players
- team_members
- phases
- groups
- group_teams
- matches
- match_sets

### Pontos interessantes para destacar no portfólio

O Mentup não deve ser apresentado apenas como "um site de campeonato".

Ele demonstra contato prático com:

- autenticação;
- sessões;
- modelagem de banco relacional;
- regras de negócio;
- relacionamentos entre entidades;
- CRUD;
- arquitetura de aplicação;
- geração automática de estruturas;
- algoritmos para organização de campeonatos;
- persistência de resultados;
- Docker;
- configuração de ambiente;
- backend e frontend integrados.

### Descrição curta sugerida

> Plataforma web para criação e gerenciamento de campeonatos de vôlei de praia, com geração automática de partidas, fases, classificação e mata-mata.

### Descrição em inglês

> A web application for organizing beach volleyball tournaments, including team management, automatic match generation, standings, group stages and knockout brackets.
